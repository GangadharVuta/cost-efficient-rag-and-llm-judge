Evaluation Architecture for Modern RAG Systems

Evaluating RAG pipelines requires separate metrics for retrieval accuracy, answer quality, and latency telemetry.

Retrieval Metrics

Retrieval evaluation relies on information retrieval (IR) metrics calculated across a test set of questions:

  • Recall@k / Hit Rate: The proportion of test queries where at least one ground-truth relevant chunk is retrieved within top-k results.
  • Mean Reciprocal Rank (MRR): Measures the reciprocal rank of the first relevant chunk retrieved across all queries.
  • Normalized Discounted Cumulative Gain (nDCG@k): Evaluates position-weighted relevance quality of top-k retrieved chunks.
  • Context Precision: The ratio of relevant chunks retrieved to the total number of chunks returned in top-k.

Answer Quality Metrics

Answer generation is evaluated along two primary dimensions: Faithfulness (groundedness in retrieved text) and Answer Relevance (directness in answering the user prompt). Exact Match (EM) and token F1 scores compare generated answers against gold human reference answers.

Latency and Cost Metrics

System performance is benchmarked using p50 (median) and p95 (95th percentile) retrieval latency. Telemetry tracks prompt tokens, completion tokens, total token count, and vector store execution time per query.
